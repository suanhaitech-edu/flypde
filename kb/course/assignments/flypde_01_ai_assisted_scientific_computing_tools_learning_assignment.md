## 一、作业名称

第一次课后 AI 辅助基础工具与飞书云文档自学作业

## 二、作业背景

本课程的核心目标，是帮助同学们完成从数学公式到可验证科学计算程序的能力转变。

在后续课程学习中，同学们不仅需要理解偏微分方程数值解的数学原理，还需要能够把数学对象、算法过程、程序实现、实验结果和学习反思清楚地表达出来。

飞书云文档是本次作业的学习起点、学习过程承载平台和最终提交载体。同学们需要先学会创建、组织、编辑、分享和维护飞书云文档，再把 Markdown、LaTeX、Linux、Git 与 AI 辅助学习过程持续记录到同一份学习笔记中。

Markdown、LaTeX、Linux 与 Git 是完成科学计算程序设计学习所需的基础工具。它们分别支撑结构化文档写作、数学公式表达、科研计算环境使用与代码版本管理。飞书云文档用于承载这些学习过程，使学习目标、操作证据、问题记录、AI 对话摘要和个人反思能够被持续整理、检查和改进。

AI 可以帮助同学们快速理解基础概念、生成入门示例、解释错误信息和改进学习笔记。但 AI 不能替代同学们自己的理解、操作、判断与反思。

本作业要求同学们以飞书云文档为基础工具，借助 AI 完成科学计算基础工具的入门学习，并形成一份结构清晰、过程真实、可持续改进的飞书云文档学习笔记。

## 三、作业目标

完成本作业后，同学们应初步具备以下能力：

1. 能够使用飞书云文档创建、组织、分享和维护课程学习笔记。
2. 能够使用 Markdown 编写结构化学习笔记。
3. 能够使用 LaTeX 表达基本数学公式。
4. 能够理解 Linux 命令行与基础文件操作。
5. 能够理解 Git 的版本控制思想，并完成本地最小操作。
6. 能够借助 AI 制定学习计划、提出问题、追问问题、理解错误与改进表达。
7. 能够把学习目标、学习过程、操作证据、问题记录、AI 对话摘要和个人反思整理为飞书云文档。

## 四、作业内容

本次作业包括六部分：

1. 飞书云文档学习笔记平台入门学习。
2. Markdown 入门学习。
3. LaTeX 数学公式输入入门学习。
4. Linux 基础命令入门学习。
5. Git 本地版本控制入门学习。
6. AI 辅助学习过程与个人反思记录。

本次作业只要求完成最小可用入门，不要求一次性精通全部工具。

## 五、学习任务要求

### 5.1 飞书云文档入门

同学们需要理解飞书云文档是本次作业的学习起点、学习过程承载平台和最终提交载体。

飞书云文档不只是提交作业的链接容器，而是帮助同学们持续整理学习过程、沉淀个人理解、记录问题、复盘成长的学习工具。

最低完成要求：

1. 能创建一份飞书云文档。
2. 能使用标题组织文档结构。
3. 能插入列表、代码块、链接、图片或截图。
4. 能在文档中记录学习目标、学习过程、操作证据和个人反思。
5. 能正确设置文档访问权限，保证教师和助教可以访问。

建议在飞书云文档中记录：

1. 飞书云文档适合用来做什么。
2. 飞书云文档为什么是本次作业的学习起点和最终提交载体。
3. 飞书云文档与 Markdown、LaTeX、Linux、Git 和 AI 辅助学习的关系。
4. 自己如何组织本次作业的学习笔记结构。
5. 自己在创建、编辑、分享或设置权限时遇到的问题。

### 5.2 Markdown 入门

同学们需要理解 Markdown 是一种轻量级标记语言，适合用于编写学习笔记、技术文档、课程总结和项目说明。

最低完成要求：

1. 能写出一级标题和二级标题。
2. 能写出有序列表和无序列表。
3. 能写出代码块。
4. 能插入一个链接。
5. 能使用 Markdown 结构整理一小节学习笔记。

建议在飞书云文档中记录：

1. Markdown 是什么。
2. Markdown 有哪些常用语法。
3. 自己写出的一个 Markdown 示例。
4. 自己在学习 Markdown 时遇到的问题。

### 5.3 LaTeX 入门

同学们需要理解 LaTeX 是科技文档和数学公式表达的重要工具。本课程中，LaTeX 的首要用途是准确表达数学公式。

最低完成要求：

至少写出以下三类数学公式：

1. 一个一元函数公式。
2. 一个偏微分方程公式。
3. 一个矩阵或向量公式。

示例：

```latex
f(x) = x^2 + 1
```

```latex
u_t - \Delta u = f
```

```latex
A\mathbf{x} = \mathbf{b}
```

建议在飞书云文档中记录：

1. LaTeX 是什么。
2. 行内公式和独立公式有什么区别。
3. 自己写出的至少三个数学公式。
4. 自己觉得最容易出错的公式写法。

### 5.4 Linux 入门

同学们需要理解 Linux 是科研计算、服务器运行、软件开发和工程部署中常用的操作系统。命令行是科学计算和程序设计的重要基础。

最低完成要求：

理解并尝试以下命令：

```bash
pwd
ls
cd
mkdir
touch
cat
cp
mv
rm
```

建议在飞书云文档中记录：

1. Linux 和命令行的作用。
2. 每个命令的含义。
3. 至少 3 条自己实际执行过的命令记录或截图。
4. 至少 1 个自己遇到的问题及解决过程。

如果暂时无法安装 Linux 或 WSL，可以先使用已有终端、在线 Linux 练习环境，或记录自己安装环境时遇到的问题。

### 5.5 Git 入门

同学们需要理解 Git 是版本控制工具，可以记录文件变化，帮助管理代码、文档和作业版本。

需要特别区分：Git 是版本控制工具，GitHub 是代码托管平台。二者相关，但不是同一个对象。

最低完成要求：

理解以下命令：

```bash
git init
git status
git add
git commit
git log
```

建议完成一个本地最小实验：

1. 新建一个文件夹。
2. 在该文件夹中初始化 Git 仓库。
3. 创建一个 Markdown 文件。
4. 使用 Git 提交一次修改。
5. 查看提交记录。

建议在飞书云文档中记录：

1. Git 是什么。
2. Git 和 GitHub 的区别。
3. 本地 Git 最小操作过程。
4. 自己对版本控制的初步理解。

本次作业不强制要求完成 GitHub 远程仓库提交。

## 六、AI 使用要求

### 6.1 可以使用 AI 完成的事情

同学们可以使用 AI 帮助完成以下学习活动：

1. 解释基础概念。
2. 制定学习路线。
3. 生成简单示例。
4. 检查命令或公式错误。
5. 解释报错信息。
6. 改进学习笔记结构。
7. 对学习笔记提出修改建议。

### 6.2 不允许使用 AI 完成的事情

同学们不得使用 AI 替代自己的学习过程。

不得出现以下行为：

1. 直接让 AI 生成完整作业后复制提交。
2. 伪造自己没有做过的操作。
3. 不理解内容就直接粘贴。
4. 用 AI 替代自己的学习反思。
5. 提交没有个人问题、个人操作和个人总结的空壳笔记。

### 6.3 必须记录的 AI 学习过程

飞书云文档中必须包含以下内容：

1. 至少 5 个自己向 AI 提出的问题。
2. 至少 2 个追问问题。
3. 至少 1 个 AI 帮助解决的实际问题。
4. 至少 1 段对 AI 回答的判断、修正或补充。
5. 至少 1 段个人反思，说明自己原来不懂什么，现在初步理解了什么，还有什么没有理解。

## 九、评价标准

本作业采用形成性评价，重点考察学习过程是否真实、结构是否清晰、是否完成最小实践、是否体现个人理解与反思。

| 评价维度    | 评价重点                                         |
| ------- | -------------------------------------------- |
| 完整性     | 是否覆盖飞书云文档、Markdown、LaTeX、Linux、Git 与 AI 学习过程 |
| 真实性     | 是否有个人问题、操作记录、错误记录和解决过程                       |
| 结构性     | 飞书云文档是否标题清楚、层次清晰、内容有序                        |
| 理解度     | 是否能用自己的话解释基本概念                               |
| AI 使用质量 | 是否体现提问、追问、判断和修正过程                            |
| 反思质量    | 是否能说明自己学到了什么、还有什么没懂                          |
| 最小实践    | 是否完成每个工具或平台的基本操作，或记录了真实尝试过程                  |

如果采用 10 分制，可参考以下评分方式：

| 项目            | 分值  |
| ------------- | --- |
| 飞书云文档结构完整     | 2 分 |
| 五类工具与平台学习记录完整 | 2 分 |
| 最小实践证据充分      | 2 分 |
| AI 提问与追问记录真实  | 2 分 |
| 个人反思具体、有成长性   | 2 分 |

也可以采用等级制：

| 等级 | 标准                  |
| -- | ------------------- |
| A  | 内容完整，有真实操作，有追问，有反思  |
| B  | 内容基本完整，有一定操作记录      |
| C  | 内容较空泛，主要是资料搬运       |
| D  | 明显复制 AI 内容，缺少个人学习过程 |

## 十、时间安排

建议完成周期为一周。

1. 第 1 天：创建飞书云文档，完成学习目标和笔记结构设计。
2. 第 2 至 4 天：完成 Markdown、LaTeX、Linux 与 Git 的最小学习，并持续记录到飞书云文档中。
3. 第 5 至 6 天：整理笔记，补充操作记录和学习反思。
4. 第 7 天：检查文档结构、访问权限和提交信息，提交飞书云文档链接。

课堂上可随机抽查同学解释一个概念、展示一个命令或说明一次 AI 追问过程。

## 十一、注意事项

1. 本次作业只要求入门，不要求精通。
2. 作业重点不是笔记是否漂亮，而是学习过程是否真实。
3. 飞书云文档是本次作业的学习起点、过程记录平台和最终提交载体。
4. AI 可以帮助学习，但不能替代学习。
5. 不会提问没有关系，提出问题本身就是训练。
6. 遇到错误时，应记录错误和解决过程，错误记录也是学习成果。
7. 不要只复制概念解释，要写出自己的理解。
8. 每个工具或平台至少保留一个最小实践证据。

## 十二、后续衔接

本作业完成后，后续课程将继续围绕以下方向展开：

1. Python 科学计算环境与 NumPy 入门。
2. GitHub 账号、远程仓库与作业提交。
3. FEALPy 安装与第一个数值实验。
4. Markdown 与 LaTeX 数值实验报告写作。
5. 期末大作业中的代码、文档、实验结果与反思报告整理。
